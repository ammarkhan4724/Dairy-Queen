# Image prompts for thequeendairymenu.us

80 prompts, one for every image the site shows. Each prompt is ready to paste into Nano Banana as is.

## Before you start

- **No logos or brand names.** The repo's rules forbid Dairy Queen logos, and candy brands (Oreo, Reese's, M&M's, Heath, Snickers, Butterfinger, Tajín) are trademarks too. Every prompt asks for plain, unbranded cups and packaging. Reject any result that shows a logo, text or garbled lettering, and regenerate it.
- **Size and format.** Generate square (1:1). Export at 600 x 600 px as WebP, quality about 80, so each file is under 80 KB.
- **File names.** Save each image with the exact file name shown, and replace the file in `public/Images/`. The pages, alt text and image sitemap already point to these names, so no code changes are needed.
- **Consistency.** Every prompt ends with the same style line, so the set looks like one photo shoot.
- **Seasonal Blizzards.** These are generic flavor images. If DQ changes a recipe, update the prompt.

Shared style line (already included in every prompt below):

> Realistic, appetizing food photography, square 1:1 frame, three-quarter angle, soft natural daylight, shallow depth of field, clean light countertop with a softly blurred warm neutral background. All cups, wrappers, trays and boxes are plain and unbranded. No logos, no text, no letters, no numbers, no signage, no restaurant interior, no people, no hands.
